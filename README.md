# bge-skimming-analytics

Genome skimming assembly and validation analytics for the [Biodiversity Genomics Europe (BGE)](https://biodiversitygenomics.eu/) project.

## About

This repository contains tools and workflows for processing, validating, and analyzing genome skimming data produced by the BGE project. The primary goal is to transform raw barcode validation outputs into high-quality, standardized, FAIR (Findable, Accessible, Interoperable, Reusable) data packages suitable for scientific analysis and reporting.

### Project Goals

1. **Data Aggregation**: Collect TSV files from barcode validator outputs across participating institutions (Naturalis, NHM)
2. **Standardization**: Define and enforce consistent column headers and metadata using the [frictionless data](https://frictionlessdata.io/) framework
3. **Quality Control**: Validate data integrity, fix inconsistencies, and ensure all files conform to the metadata specification
4. **FAIR Publishing**: Package validated data as [RO-Crate](https://www.researchobject.org/ro-crate/) archives with DOIs for long-term preservation and citation

### Data Processing Workflow

1. **Collection**: TSV files are generated by the [barcode validator](https://github.com/naturalis/barcode_validator) and aggregated in this repository
2. **Metadata Definition**: Column headers are defined in `metadata/headers.tsv` following frictionless data specifications
3. **Data Cleaning**: Automated scripts fix common issues (column naming, redundant fields, parsing structured identifiers)
4. **Validation**: All files are validated against the metadata specification
5. **Packaging**: Clean data is combined with metadata into frictionless data packages
6. **Archival**: RO-Crate packages are uploaded to Zenodo with DOIs, optionally linked to BOLD datasets

## Getting Started

### Prerequisites

```bash
# Create conda environment from environment.yml
conda env create -f environment.yml
conda activate bge-skimming-analytics
```

### Repository Structure

```
bge-skimming-analytics/
├── data/              # TSV files from barcode validation (naturalis/, nhm/)
├── docs/              # Detailed documentation for data processing steps
├── metadata/          # Column definitions and metadata specifications
├── scripts/           # Data processing and analysis tools
└── tests/             # Unit tests for validation and processing scripts
```

### Quick Start

See the [scripts/README.md](scripts/README.md) for available tools and usage instructions.

For detailed information about data processing steps and fixes applied, see the [docs/](docs/) folder.
